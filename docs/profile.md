# 수사관 프로필과 명함

커스터마이징 버튼은 프로필 / 종족 / 특성 / 권한 / 특수다. 프로필은 맨 위에서 두 칸을 차지하며, 종족은 별도 팝업에서 선택한다. 명함에는 선택 결과를 표시한다. 기존 머리·눈·가슴 크기와 부가 외형 옵션은 제거했다.

프로필은 `build.profile`에 portrait(증명사진 data URL), race(종족 선택에서 만들어지는 표시 문구), intro(자기소개), height(cm), weight(kg), themeColor(명함 강조색), cardTheme(명함 레이아웃), collectible(전시할 수집품 ID)을 저장한다. 성별과 이름은 기존 build.gender와 build.name을 사용하며 프로필 편집기에서 바꿀 수 없다. 명함 테마는 glass / archive / noir다. 사이트 전체 테마와 명함 레이아웃은 별개 설정이다.

이전 세이브의 build.appearance.portrait와 height는 새 프로필에 이관된다. 프로필 필드가 이미 있으면 새 값을 우선한다. 나머지 옛 외형 필드는 새 저장 코드에 포함하지 않는다. 기존 컷씬·이름·성별·스탯·스토리 진행 기록은 유지한다. 세이브는 기존 GAL2 형식을 유지하며 normalizePlayer에서 마이그레이션한다.

수집품 획득 목록은 save.collectibles에 ID 배열로 보관하며 내보내기/불러오기에 포함된다. 작품의 project.collectibles에 {id,name,description}을 등록하면, 보유 ID와 교집합인 항목만 선택 창에 나온다. 업적 달성/사건 보상 처리에서 조건을 판정한 뒤 해당 ID를 목록에 추가하면 된다. 현재 실제 수집품 및 지급 조건은 등록하지 않았다.

명함 수집품 전시는 프로필을 확정한 뒤에만 선택할 수 있다. 선택 및 명함 출력 양쪽에서 보유 여부를 확인한다. 전시를 해제할 수도 있다. 추후 수사 탭의 인벤토리도 같은 save.collectibles를 읽도록 연결한다. 수사 탭은 아직 추가하지 않았다.

사진은 기존의 크기 축소, 용량 제한, 업로드 취소/경합 방지, 저장 실패 시 이전 값 보존 처리를 사용한다. 입력 문구는 HTML 이스케이프하여 명함에 표시한다. 키 범위는 120~220cm, 몸무게 범위는 20~250kg이며 향후 세계관에 맞춰 변경할 수 있다.

## 종족과 사고 한계

`build.race`에는 primary, secondary(종족 ID), immortal(영생종), mixed(혼혈), divisions(종족 ID → 분화 ID)를 저장한다. 종족 ID는 human, elf, dwarf, beastkin, celestial, demon, spirit, automaton이다. 기본 종족은 단일 선택이며, 혼혈을 켜면 다른 종족 하나를 추가 선택한다. 혼혈을 끄거나 두 선택이 중복되면 secondary를 비운다. 영생종은 독립적인 추가 분류다. 빌딩 확정 시 기본 종족이 필요하며, 혼혈이면 두 번째 종족도 필요하다. 기존에 확정한 세이브는 확정 상태를 보존한다.

기존 profile.race 문구가 8종족 이름과 정확히 일치하면 해당 ID로 이관한다. 그 외 예전 자유 입력은 새 선택 전까지 명함에 보존한다. 새 종족을 고르면 표시 문구가 선택된 종족·분류로 대체된다.

`project.raceDetails[종족 ID]`에 `traits: [{name,description}, ...]`와 `divisions: [{id,name,description}, ...]`를 넣으면 된다. 고유 특성은 세 카드로 표시한다. 현재 실제 특성과 분화 목록은 제공받지 않아 미등록 상태다. 특성 보너스·비용은 적용하지 않는다. 테스트용 정의는 검증 중에만 임시 등록된다.

`build.thoughtLimitBase`는 기본 사고 한계 수치이며 0~1,000,000 정수다. 초기값은 아직 지정되지 않아 임시로 0을 사용한다. 표시·저장용 합계인 `build.thoughtLimit`는 기본값과 종족 분류의 기여분을 합산한다. 빌딩 중에는 화면 아래 및 커스터마이징 팝업 아래에 표시한다. 확정 후에는 빌딩 탭의 신상 요약에만 작은 회색 텍스트로 표시하고, 다른 탭에서는 숨긴다. 코드 내보내기·복원 및 컷씬 이동에 수치가 보존된다.

혼혈은 별도 종족 그리드를 열지 않고 같은 8개 버튼을 사용한다. primary는 먼저 선택한 종족, secondary는 나중에 선택한 종족이다. 두 종족을 고른 상태에서 다른 종족을 누르면 나중 선택을 교체한다. 혼혈 모드에서 선택한 버튼을 다시 누르면 해당 선택을 해제하며, 첫 선택을 해제하면 두 번째를 첫 선택으로 옮긴다. 혼혈을 끄면 현재의 나중 선택만 해제한다. 명함에는 두 종족 이름을 표시하되 ‘혼혈’이라는 부가 표기는 넣지 않는다. 영생종 표시는 유지한다.

분화 제목은 ‘분화: 종족명’이며 고유 특성 카드는 모바일을 포함해 가로로 긴 카드 세 장을 세로로 쌓는다. 카드 왼쪽에는 특성 제목, 오른쪽에는 설명을 배치하며 가로 스크롤은 사용하지 않는다. 사고 한계 표시는 현재값/250 형식이다. 표시 분모는 250이며, 기본 수치와 현재 적용된 종족 분류의 기여분을 합산해 분자를 표시한다.

영생종의 실험용 사고 한계 기여분은 `IMMORTAL_THOUGHT_COST = 251`이다. 선택하면 기본 수치에 251을 더하고 해제하면 기본 수치로 돌아간다. 이전 세이브에 thoughtLimitBase가 없다면 종전 thoughtLimit를 기본값으로 옮긴다. 새 세이브는 기본값과 합계를 함께 저장하므로 재계산·불러오기 때 반복 가산하지 않는다. 향후 비용 설정 변경은 이 상수/기여분 계산을 변경하면 된다.

영생종·혼혈 버튼에는 ON/OFF 문자를 표시하지 않고 aria-pressed, 배경색, 테두리로 상태를 구분한다. 빌딩이 미확정이고 합계가 250을 초과할 때만 포인트 표시 위에 붉은 붕괴 효과를 출력한다. 250 이하는 효과가 없고, 확정 뒤에도 표시하지 않는다. 효과는 다섯 개의 고정된 그라데이션 레이어로 구성되며 포인터를 막지 않는다. 모션 감소 환경에서는 움직임 없이 붉은 기운만 표시한다.

붕괴 경고는 뾰족한 파편·균열 대신 부드러운 붉은 안개가 서로 다른 주기로 일렁이며 번지는 형태다. 초과 상태에서만 ‘사고 한계’ 글자에 두 개의 장식용 복제층과 불규칙한 위치 왜곡을 적용한다. 복제층은 aria-hidden으로 중복 낭독을 막는다. 효과와 글리치는 CSS 애니메이션이며 타이머나 새 파티클의 지속 생성은 없다. 모션 감소 설정에서는 움직임을 끄고 정적인 경고 색을 유지한다.

## 오토마타와 레플리카

오토마타가 포함된 조합은 항상 primary=automaton으로 정규화한다. 두 번째로 오토마타를 골랐거나, 이전 저장 코드에서 secondary에 오토마타가 들어 있던 경우에도 우선순위를 바꾼다. 이 경우 일반 선택 순서 규칙보다 오토마타 우선 규칙이 먼저 적용된다.

오토마타를 선택하면 mixed 버튼의 표시 이름은 ‘레플리카’다. 저장 필드는 기존 mixed를 그대로 사용한다. 레플리카를 켠 뒤 실제 두 번째 종족을 골랐을 때, 두 번째 종족의 고유 특성 카드는 DOM에 출력하지 않으며 오토마타의 숨겨진 네 번째 특성을 공개한다. 두 번째 종족의 분화 영역과 명함의 종족 표시는 유지한다.

숨겨진 특성은 project.raceDetails.automaton.traits[3]의 name/description에서 읽는다. 내용이 없으면 미등록 카드로 표시한다. 레플리카를 해제하거나 두 번째 종족을 해제하면 네 번째 특성도 숨긴다. 오토마타 선택을 해제하면 버튼 이름이 혼혈로 돌아온다. 임의의 능력·비용은 추가하지 않았다.

## 미래의 사고 한계 확장

빌딩 미확정 상태에서 현재 수치가 최대치를 초과하고 도움을 아직 받지 않았을 때 SD 도움 버튼을 표시한다. 최대치는 thoughtLimitMaximum(build)에서 계산하며 기본 250, build.thoughtGiftReceived=true이면 300이다. 현재 사고 한계 수치를 줄이거나 증가시키는 효과가 아니라 최대치를 50 확장하는 효과다.

도움을 받으면 grantThoughtGift가 기록을 한 번만 적용한다. 완료된 빌딩, 초과하지 않은 상태, 이미 받은 상태에서는 다시 적용할 수 없다. 확장 기록은 세이브 코드와 브라우저 저장에 포함하며 다시 빌딩해도 유지한다. 새 플레이어 데이터로 초기화할 때만 해제한다. 붕괴와 글리치는 고정 250 대신 현재 최대치를 기준으로 판정한다. 300을 넘으면 경고가 다시 나타나지만 도움을 중복 수령할 수는 없다.

SD는 화면 오른쪽의 단일 전역 레이어에서 살랑이는 버튼이며, 팝업에서도 선택할 수 있다. 누르면 별도 대화창 없이 SD 주위에 보라색 마법 반짝이가 터지고 말풍선으로 대사를 표시하며 SD가 오른쪽으로 들어간다. 대사 속 오빠/언니는 기존 성별에 따라 치환한다. 열려 있던 커스터마이징 창은 유지하며, 연출은 3.6초 뒤 정리한다. 최대치 숫자는 보라색 프리즘으로 표시하고 모션 감소 환경에서는 정적으로 표시한다.

사용 원본 파일: dist/assets/thought-assist-sd-c817b19264.webp. 첨부된 원본을 변형 없이 복사했다. prepare-release에서 이미지 누락 시 배포를 막고, verify-deployment에서 배포된 이미지의 실제 바이트를 검증한다.

LD 스탠딩과 별도 대화창은 제거했다. 연출 중 반복 클릭은 기존 수령 기록으로 차단하며, 애니메이션이 끝나기 전 다른 입력으로 화면을 다시 그려도 경과 시간을 CSS 지연에 반영해 처음부터 재생하지 않는다. 팝업을 닫아도 진행 중인 말풍선·퇴장 연출은 전역 레이어에서 계속된다. 마법 효과·SD·말풍선은 포인터를 막지 않는다. 수령 기록은 클릭 시 저장하고 연출은 일시적 상태로만 유지한다.

미래 레이어는 하나의 DOM 호스트를 재사용한다. Popover API의 manual popover로 브라우저 최상단 레이어에 올린다. 모달이 열리면 같은 호스트를 모달의 자식으로 옮겨 모달 바깥의 inert 처리에 막히지 않게 하고, popover로 다시 올려 backdrop보다 앞에 표시한다. 모달을 닫으면 같은 호스트를 body로 옮긴다. popover의 fixed 위치는 화면 기준이며 탭의 필터/스크롤/클리핑과 분리된다. 두 포인트 바에서는 SD를 더 이상 출력하지 않는다.

Popover API가 없는 환경은 같은 호스트를 활성 모달로 옮기고, 해당 모달의 containing-block을 만드는 필터·변환만 잠시 해제하는 대체 처리를 사용한다. 도움 대상이 아니거나 시작 화면/빌딩 확정 상태면 호스트를 숨긴다. UI 검증은 호스트 재사용, 모달 이동, 중복 방지, 대체 처리, 말풍선 연출 유지와 정리를 검사한다.

## 종족 선택 이미지

raceArtwork는 elf / beastkin / demon / automaton의 선택 버튼 배경을 지정한다. 현재 사용자 지시의 첨부 순서(엘프, 수인, 마족, 오토마타)대로 매핑할 준비를 해 두었다. 이미지는 명칭 아래의 별도 아이콘이 아니라 버튼 전면에 표시하고, 이름과 선택 순서는 어두운 그라데이션 위에 표시한다. 메뉴 심볼 반전 필터는 종족 일러스트에 적용하지 않는다.

휴먼·엘프·드워프·수인·천족·마족·정령·오토마타의 선택 버튼에는 전달된 원본 이미지를 연결했다. 원본이 없는 버튼은 기존 아이콘 자리와 이름을 유지한다. release에서는 등록된 파일의 존재를 검사하고, 배포 시 이미지 바이트도 검증한다.
